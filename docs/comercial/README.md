# Material comercial de INsight

| Archivo | Para qué |
|---|---|
| `INsight_OnePager.md` | Una página para C-Level: oportunidad, qué es, por qué INFILE, estado, siguiente paso |
| `INsight_Costos.md` | Costo AWS por cliente, precios sugeridos, márgenes, punto de equilibrio |
| `brand/insight-logo.svg` / `.png` | Logo horizontal, fondo claro (correo, documentos) |
| `brand/insight-logo-dark.svg` / `.png` | Logo horizontal, fondo oscuro (presentaciones) |
| `brand/insight-icon.svg` / `.png` | Isotipo cuadrado (favicon, avatar, redes) |

Reglas de marca: "IN" siempre en azul `#3b8df5`; "sight" en `#102a43` sobre claro o blanco sobre
oscuro. Nunca `InSight`, `In-Sight` ni las dos mitades del mismo color. Tagline: *Insight desde
adentro de su facturación.*

Los `.png` están a 2× para pantallas de alta densidad. Para regenerarlos tras editar un `.svg`,
cualquier conversor SVG→PNG sirve (Inkscape, `rsvg-convert`, o abrir el SVG en el navegador).
